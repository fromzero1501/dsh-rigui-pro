# dsh-rigui-pro · 日晷 Pro

给 DeepSeek Harness 的个人生活工作台。睡眠、饮食、运动、花销、体重、日程和待办放在同一页卡片上，而且彼此联动：说一句「早饭 两个麻团 一杯豆浆 8」，热量、花销、今天的时间线会一起动起来。

在日晷之上，Pro 多做了两件事：**说一句就排一天**（把「要做的事」拆进今天的时间块，你逐条取舍），**琐事按规律提醒**（喝水、吃饭、洗澡、洗头按各自节奏弹提醒，可标「做了 / 15 分钟后 / 不用了」）。

装好后，左侧边栏多出一行「日晷 Pro」，点开就是工作台。点一下问候语可以告诉它怎么称呼你；在主卡片右上角输入城市，就能看到当地天气。

![日晷工作台](assets/workbench.png)

## 安装

```sh
dsh plugin --profile web add github:fromzero1501/dsh-rigui-pro
```

桌面客户端把 `web` 换成你在用的 profile（例如 `desktop`）。装好后重启一次 DSH。

本机开发时也可以直接链一份源码：

```sh
dsh plugin --profile desktop add link:D:/path/to/dsh-rigui-pro
```

## 说一句就排一天

输入框里出现「安排、排一下、计划、时间表、怎么过」这类说法时，不再走记录解析，而是进排程：

- AI 拿到今天已有的日程（当锚点，不许重叠）、待办、目标、睡眠、天气，把要做的事拆成一个个时间段，标好「办事 / 干活 / 生活 / 运动 / 休息」
- 每条都能单独点掉；不满意就在输入框里说「下午要出门，重排」，它按新约束再来一版
- 按「就按这 N 件走」落到时间线，卡片跟着一起动

## 琐事按规律提醒

「日常」卡片管四件最容易忘的事，各有各的节奏：

| 事项 | 默认节奏 | 说明 |
| --- | --- | --- |
| 喝水 | 在电脑前坐满 90 分钟（09:00–21:00） | 单独一张「喝水」卡：点一下杯子水位涨一格，8 杯满格停住，零点归零，点错了能「减一杯」 |
| 起身 | 在电脑前坐满 50 分钟 | 离开超过 5 分钟就重新计时，不按钟点 |
| 早餐 / 午餐 / 晚餐 | 07:30 / 12:00 / 18:00 | 固定时刻 |
| 洗澡 | 每 3 天 22:30 | 洗一次管三天，按钮到点前灰着 |
| 洗头 | 每 3 天 21:30 | 按上次记录往后推 |

点卡片背面的开关可以逐项关掉，喝水间隔能 ±15 分钟调，起身阈值能 ±10 分钟调，洗澡洗头间隔能 ±1 天调。提醒走系统通知，23:30–07:30 免打扰（睡觉那条除外），点「15 分钟后」就顺延，不再重复轰炸。

待办和日程到点也会提醒：说事的时候带上钟点（「九点提醒我交稿」）就有那一刻的提醒；排进日程的块会在开始前 5 分钟提醒（分钟数在语音面板里调）。这两类不受深夜免打扰限制——你排在那个点的事本来就是要它响的。点「做了」会把对应的待办或日程标记完成。

口头说「喝了杯水」「刚洗完澡」「今天洗头了」也会直接记进日常，不用点卡片。

## 在不在电脑前

「日常」卡抬头右侧有个状态点：**专注中**（连着在电脑前 ≥10 分钟）、**在电脑前**、**离开了**（多久没碰键鼠）、**未在监测**（采样器没起来）。

判断只读系统的「距上次输入过了多久」，不记录你敲了什么、也不看前台窗口——口径是「人在不在」，不评判你在干什么。采样由插件自带的一个小程序做（`native/idlewatch.exe`，Go 编译，约 1.8 MB，常驻内存几 MB），每 30 秒回报一次；它随 DSH 启停，宿主一退管道就断、它自己收工，不留孤儿进程。缺这个程序时状态点会写「采样器没装」，其余功能照常。

喝水和起身都按「一直在电脑前坐了多久」算：你离开超过 5 分钟，计时就停、回来重新累计，所以出去一趟回来不会立刻被连着催。

## 念出来

到点除了弹通知，还能念一句。文案是固定几句轮换的，不为了朗读去调模型；同一句话只合成一次，之后按「配置 + 文案」命中缓存（`$DSH_HOME/rigui-pro/voice/`，最多留 200 条）。

三路都支持，点页面顶部（问候语右侧）的 **🔊 语音** 打开配置面板（全屏面板：总开关、云端／MiMo／本地切换、哪几类要念、逐项要不要念、日程提前几分钟、播放器与缓存状态）：

- **云端**：任何 OpenAI 兼容的 `/audio/speech`（地址、密钥、模型、音色自填；密钥按你的要求明文落在 `$DSH_HOME/rigui-pro.json`）。
- **小米 MiMo**：官方标的是限时免费，走的是 chat/completions 形状（不是 `/audio/speech`），所以单开一路；默认 `https://api.xiaomimimo.com/v1` + `mimo-v2.5-tts`。模型和音色都是下拉框：内置 9 个音色（`mimo_default`、冰糖、茉莉、苏打、白桦、Mia、Chloe、Milo、Dean），另外可以「照我的录音克隆」——在「参考音频」里选一次 `.mp3` / `.wav`，超过 30 秒会自动裁短压小，文件存在本机 `$DSH_HOME/rigui-pro/voices/`；挑到「我的音色」时模型自动切成 `mimo-v2.5-tts-voiceclone`，每次合成把这段录音一起发给 MiMo（服务端不存音色 ID）。要念的文字会放进 `role: assistant` 的消息里。
- **本地 IndexTTS**：填 Gradio 服务地址（默认 `http://127.0.0.1:7860`）、接口名（默认 `gen_single`）和参考音频；默认发 `["文案","参考音频"]`，接口参数不一样就在「参数模板」里写一个 JSON 数组，用 `{{text}}` / `{{voice}}` 占位。

每件事旁边有个小喇叭：亮着就会念，点一下先听这句，再点一下这件事就不念了。待办和日程念的是「事情标题 + 固定后缀句」，生活琐事念的是固定句池。播放用 ffplay（装个 ffmpeg 就行），同一时刻只响一条；23:30–07:30 只静音生活琐事，待办和日程照念。

两件事保证「最后一个字不被切」：一是合成完先给音频末尾补 0.45 秒真静音（ffplay 读到文件尾就关声卡，尾巴不留缓冲就会被切掉半个字），补完再量末尾静音，不够就重合成；二是到点先用后台把这条备好，还没备好时提醒卡上会显示「语音还在备，好了马上念」，备好就播，不会漏念。

## 说一句就记下

顶部输入框随口说，AI（用你在 DSH 里选的默认模型，优先同家的快速模型）会拆成结构化记录：

- 吃了什么：每样食物单独估热量，数字不对可以直接改，下次会记住
- 花了多少、收入多少
- 练了什么、多久、多少步
- 几点睡、几点起，体重
- 以后要做的事（日程）和没有具体时间的事（待办）
- 「一周前体重 83.2」「上周三跑了 5 公里」这类说法会记到那一天

AI 不可用时有本地规则兜底。

## 主卡片：天气和日程

- 主卡片接实时天气（Open-Meteo，不用 key），没有自己的底色，和整页背景连成同一片天空（见下面的「日夜和天气」）
- 右上角只留城市、现在的温度和今天的高低温；点这三处任意一处，主卡片换成天气页（不翻卡：前景退进雾里，温度从右上角飞到左边放大，7 天一列列浮上来）：左边是现在的天气，右边是像 iOS 天气小组件那样一天一列的 7 天预报（降水概率、温度区间条），点页面任何地方翻回来；背面点城市名可以换城市
- 正在开会、学习、运动的时候，右上角显示这段日程还剩多久
- 天气也会进「它们之间的关系」：要下雨时提醒户外运动、太热补水、太冷保暖
- 左边只留一个入口：输入框。点进去才浮出该记的事和常记的话，平时是一句今日小结和一条关系提示；右边的靶子是「目标」

## 卡片之间是连着的

- 记一笔，一道道光从输入框连到受影响的卡片，卡片依次闪一下
- 练得越多，「今天还能吃」越多；勾掉带金额的待办，自动记一笔账
- 「它们之间的关系」把睡眠、吃饭、运动、花钱之间的因果找出来，鼠标停上去，一条带彗星的弧线精确连到两张卡里对应的数字

## 动效

每张卡都有自己的手感，不是一套动效套所有卡片。

- **卡片**像挂在线上的工牌：鼠标扫过会被托起、荡一下，同一排的邻居跟着晃；能拖动、能像桌面小组件一样改大小
- **今天还能吃**是一管橙色汽水，在管子上滑动就是「试吃」：液面追着鼠标流过去，冒气泡，超过上限的那段变红
- **这个月还能花**每天一只小钱罐，装了多少就是花了多少；鼠标靠近像点阵一样鼓起来
- **小票打印机**：卡片底边裂开出纸口，热敏小票一格一格吐出来；往下扯，沿着出纸口撕断，同时存成图片（可选每次问、固定文件夹或「下载」）
- **睡眠**卡里藏着一片星星，鼠标像一盏小灯照亮附近的；**运动**柱子像琴键，划过哪天哪根就跳
- **翻面**：点一下卡片，背面写着这个数字是怎么算出来的
- **要做的事**：勾掉的事飘到已完成里；删除时字碎成屑飞走，原地留 4 秒倒计时撤销；清掉的事收在背面，可以放回去
- **体重**蒙着一层雾玻璃，来回擦几下才看得见；只擦了一半就停手，擦过的地方会慢慢重新起雾；擦开后走开一会儿，整张又起雾
- 全部做完有一段按顺序走的庆祝；系统设置了减少动态效果时，动效会收敛

## 目标

输入框右边的靶子按钮打开「目标」：按你记下的数据给出六层建议（每日任务、这个月、一年、愿景、反愿景、底线），结构参考 Dan Koe《How to fix your entire life in 1 day》。采纳一项，就往靶子对应那一圈扔一支飞镖；六层都点亮，靶子转一圈锁定。采纳的数字会回到工作台，比如每天的热量目标、每月预算。

## 日夜和天气

整页就是窗外的天。

- **日夜跟着太阳走**：日出后是白天，日落后入夜。主卡片左上角有个天空开关，滑块是太阳或月亮，手感像一团果冻：按下压扁、粘一下再被扯开、撞到头弹两下；也能按住拖。手动拨过的，保持到下一次日出或日落
- **夜里**整页是一片星空，拨到夜间时星星从开关停下的位置往外一圈圈亮起；卡片换成带蓝调的深色，彩色卡片保持原色
- **白天**整页是当地当时的天空：
  - 晴天卡片有投影，方向和长短跟着太阳转，上午朝右、中午短、下午朝左，日落前一小时变暖金色
  - 多云有云影从卡片上飘过；阴天、雾天整页灰下来，投影只剩正下方一圈
  - 雨天、雪天只在打开日晷（或者天气刚变成雨雪）时下十秒左右，雨丝随风倾斜、打在卡片上沿溅起水花，最后两三秒渐渐停；雪会贴着卡片顶边和圆角积起来，按今天下了多久预先铺好；雷雨天会闪一下
  - 天黑后拨回白天，是「屋里开着灯」：暖白背景，影子落在正下方，不显示天气
- 背景里一直在动的只有云和雾的缓慢飘移，交给显卡做；系统设置了减少动态效果时只留静态画面

## 数据

所有记录都存在本机浏览器存储里，不上传到任何地方。只有你说的那句话会发给你在 DSH 里配置的模型来解析；查天气时只把城市名和经纬度发给 Open-Meteo。

## 开发

```sh
npm install
npm run build         # 生成 client.js、index.js 和 dist/preview.html
npm run build:native  # 编译 native/idlewatch.exe（需要本机有 Go；没编也能跑，状态点显示「采样器没装」）
```

- `src/host.js`：主机半边，注册 `/api/rigui-pro` 路由（`parse` / `plan` / `replan` / `coach` / `routine` / `voice` / `ai` / `activity`），调用 DSH 的模型解析一句话、排一天、给建议，把琐事的规则、到期时间与活动采样存进 `$DSH_HOME/rigui-pro.json`
- `native/idlewatch/main.go`：活动采样小程序（读 `GetLastInputInfo`，每 30 秒往 stdout 打一行 JSON；父进程没了就自己退）
- `src/plugin.jsx`：浏览器半边，注册侧边栏入口和主区域页面
- `src/habits.js` / `src/habits.jsx`：琐事的规则、默认节奏、本地兜底识别，以及「日常」卡片、卡片背面和提醒条
- `src/plan.jsx`：排程结果面板（逐条取舍、说一句重排）
- `dist/preview.html`：不依赖 DSH 的预览页，直接用浏览器打开
